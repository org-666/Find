# Find 产品架构文档

**一句话定位**：Find 不是社交 App，是「此刻启动器」。用户说想干嘛，系统自动匹配附近同时段也想做这件事的人，AI 助手替双方完成第一轮确认，双方确认后开临时对话，做完散，不留痕迹。

---

## 一、核心设计原则

1. **不展示人，只展示进度**：用户全程不做「选择人」这个动作，只做「去 / 不去」的确认。
2. **AI 接管匹配**：系统自动筛选、自动替双方做第一轮确认，用户只看到结果。
3. **做完即散，不留痕迹**：局结束自动删除，没有好友、没有记录、没有「想认识」。
4. **想再约？重新匹配**：不靠记忆，靠实时重合。下次各自发需求，如果又匹配到彼此，说明此刻又重合了。
5. **位置永远模糊化**：对外只显示「XX 米内」，不暴露精确坐标。
6. **年龄门槛**：仅面向 18-30 岁，注册时自动校验。

---

## 二、功能模块

### 模块 A：用户与认证
- 注册/登录（手机号 + 验证码）
- 年龄校验：18-30 岁，超出无法完成注册
- 基础资料：昵称、头像、城市
- 位置授权：获取经纬度，网格化到 100m

### 模块 B：说需求（AI 解析）
- 一个输入框，支持自然语言
- 用户输入「想动一动」「有点饿」「想找个人一起」等模糊表达
- AI 助手把模糊需求翻译成结构化标签（运动 / 吃饭 / 自习 / 游戏）
- 解析完让用户确认：「你是想打羽毛球，对吧？」
- 确认后进入匹配池

### 模块 C：自动匹配（AI 中介）
- 系统在附近同时段、同活动的人里筛选
- 不展示人，只展示进度：「正在找附近也想打羽毛球的人…」
- 匹配到后，**AI 助手替双方做第一轮确认**
- AI 自动问对方：「有人也想打羽毛球，3 分钟后到 XX 场地，去吗？」

### 模块 D：双方确认
- 用户只看到 2 个按钮：**去 / 算了**
- 双方都点「去」→ 开临时对话
- 任何一方点「算了」→ 回到匹配池，继续找

### 模块 E：临时对话
- 只有 3 个按钮：**我到了 / 我晚点 / 算了**
- AI 在用户不知道说什么时给一句建议（如「问问他到哪了」）
- 但对话主体是人，AI 不替人聊天
- 局结束后自动关闭，系统不留记录

## 三、技术栈

| 层 | 选型 | 理由 |
|---|---|---|
| 前端 | Next.js + Tailwind | 快速出原型，Vercel 一键部署 |
| 语言 | TypeScript | 类型安全，和 Supabase 配合好 |
| 实时通信 | Supabase Realtime | 匹配进度、临时对话 |
| 数据库 | Supabase Postgres | 用户、需求、匹配、会话 |
| AI 解析 | DeepSeek API / OpenAI API | 把模糊需求翻译成标签 |
| 定位 | 浏览器 Geolocation API | 原型阶段够用 |
| 认证 | Supabase Auth | 手机号登录 |
| 部署 | Vercel + Supabase | 全免费，个人项目够用 |

## 四、数据模型（极简版）

- **users**：id, nickname, avatar, age, city, location_grid, created_at
- **moments**：id, user_id, raw_input, activity_tag, time_window, status, created_at
- **matches**：id, moment_a, moment_b, status, created_at
- **sessions**：id, match_id, status, created_at, expires_at
- **ai_sessions**：id, user_id, moment_id, status, created_at

## 五、开发顺序

1. 项目初始化 + 注册 + 基础资料（含 18-30 校验）
2. 发需求 + AI 解析模糊输入
3. 自动匹配 + AI 替双方确认
4. 双方确认 + 临时对话 + 自动关闭
5. 部署上线，拉朋友测

---

## 六、测试阶段唯一指标

**有没有人「主动发第二次需求」。**

- 只有你发、朋友响应 → 不算验证
- 有朋友自己主动发了一条 → 逻辑成立
- 所有人都只是「你拉我就来」→ 需要重新想

---

## 七、AI 助手的边界（重要）

**AI 只做两件事：**
1. 把用户的模糊需求翻译成结构化标签
2. 替双方完成第一轮时间地点确认

**AI 不做的事：**
- 不替用户聊天
- 不生成临时对话内容
- 不在用户明确表达后自作主张
